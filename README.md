# 🚗 Premium Vale Website

🔗 **Live Demo:**
https://vale-website-sepia.vercel.app/

Modern, premium ve dönüşüm odaklı bir vale hizmeti web sitesi.

Bu proje, müşteri ihtiyaçları doğrultusunda geliştirilmiş modern bir kurumsal landing page çalışmasıdır. Amaç yalnızca estetik bir arayüz oluşturmak değil; kullanıcı deneyimi, responsive tasarım, performans ve modern frontend mimarisini bir araya getirerek profesyonel bir web deneyimi sunmaktır.

---

## 🚀 Features

* 🚗 Premium vale hizmet tanıtım alanları
* 💼 Kurumsal ve güven veren tasarım dili
* 📱 Mobil / Tablet / Desktop uyumlu responsive yapı
* ⚡ Optimize edilmiş performans odaklı sayfa yapısı
* 📩 İletişim ve dönüşüm odaklı form alanı
* 🧩 Component-based frontend architecture
* 🔝 Scroll-to-top kullanıcı deneyimi desteği
* 🔍 SEO uyumlu sayfa altyapısı
* ☁️ Vercel deployment

## ⚙️ Installation

Clone the repository:

```bash
git clone <repo-url>
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Start production server:

```bash
npm start
```
